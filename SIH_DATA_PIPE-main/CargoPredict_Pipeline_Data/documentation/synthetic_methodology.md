# Synthetic Data Methodology

Generator seed: 26006. Date coverage: 2020-01-01 to 2026-08-31.

Synthetic route freight is a bounded scenario function of distance, vessel class, a simulated dry-bulk index, VLSFO, congestion, storm events, vessel supply, fixture activity and random noise. This creates plausible relationships for integration and pipeline testing; it is not an estimate of historical market prices. Weather, congestion, vessel supply and fixture activity are also simulated. Every generated file and row includes an explicit synthetic marker.
